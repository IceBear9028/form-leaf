# 12. 정적 분석 정책과 적용 설계

## 작업 소개

**Formleaf의 TypeScript·ESLint 검사 범위와 허용 기준을 정하고, 기존 동작을 보존하는 적용 방법을 설계한다.**

- 대상: 제품 코드·테스트·개발 도구를 수정하는 개발자와 리뷰어.
- 상태: 정책·문서 완료, 기능별 구현·검증 진행. 실제 상태·커밋은 plan에서 관리한다.
- 코드 기준: `989a7f6`, 분석·작성일 `2026-11-08`.

## 핵심 변화

**기존 타입 검사에 실행 환경 경계, Promise 책임, 테스트와 React 동작 검사를 추가하는 기준을 확정했다.**

- 변경 전: 단일 tsconfig가 제품 소스 위주로 검사하며 ESLint 검사는 없다.
- 목표: 오류는 필수 검사에서 차단하고, 검토가 필요한 React·접근성 경고는 별도로 노출한다.
- 이번 변경: 합의한 정책에 따라 검사·소스·테스트를 기능별로 적용하고 결과를 기록한다.
