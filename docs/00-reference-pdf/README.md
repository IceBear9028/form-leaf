# 00. 첨부 PDF 재현 및 PDF 내보내기

## 상태

구현 중

## 목표

사용자가 제공한 이력서 PDF의 시각적 구조를 앱에서 재현하고, 입력한 데이터를 같은 형태의 A4 PDF로 내보낸다.

참조 파일:

```text
/Users/isang-yun/Desktop/이력서.pdf
```

참조 PDF는 6페이지이며 프로필, 소개, 경력, 교육, 프로젝트, 사이드 프로젝트와 대외활동으로 구성되어 있다.

## 이번 작업에 포함

- Electron 앱 실행 환경
- 프로필 내용 입력
- 소개글 입력
- 프로젝트별 입력
- 프리텍스트 입력
- 참조 PDF에 필요한 경력·교육·대외활동 표현
- 문단 내부의 굵게, 밑줄과 링크 정보 보존
- 참조 PDF 전용 내장 스타일
- 콘텐츠 편집에 집중한 좌측 편집기와 우측 A4 미리보기 UI
- A4 다중 페이지 미리보기
- 프로젝트가 다음 페이지로 이어지는 레이아웃
- 로컬 자동 저장
- PDF 파일 내보내기
- 참조 PDF와 결과 PDF의 페이지별 시각 비교

## 이번 작업에서 제외

- 여러 이력서 버전 관리 UI
- 스타일 편집 UI
- 색상 선택, 글꼴 선택과 간격 조정 UI
- 여러 디자인 템플릿
- 조밀도 프리셋
- 한 페이지 초과 경고
- JSON 가져오기·내보내기 UI
- 포트폴리오 생성
- 클라우드 동기화와 계정
- 시스템 프린터 인쇄
- 자동 업데이트와 외부 배포 준비

제외된 기능을 가정해 화면이나 흐름을 구현하지 않는다. 다만 데이터는 특정 UI나 현재 스타일에 종속되지 않도록 설계한다.

## 완료 조건

- 참조 데이터로 A4 6페이지가 동일한 순서로 렌더링된다.
- 페이지별 여백, 열 구조, 제목 계층, 구분선, 들여쓰기와 페이지 번호가 참조 PDF 수준의 완성도로 재현된다.
- 여러 페이지에 걸친 프로젝트의 연결 방식이 참조 PDF와 일치한다.
- 미리보기와 최종 PDF의 줄바꿈과 페이지 분리가 일치한다.
- PDF 텍스트를 검색하고 복사할 수 있다.
- 앱을 종료하고 다시 실행해도 입력 데이터가 복원된다.
- 사용자의 문장을 자동 작성하거나 요약하지 않는다.
