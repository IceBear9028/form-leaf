# 참조 PDF 분석

## 문서 구성

| 페이지 | 주요 구성 |
|---|---|
| 1 | 프로필, 소개, 경력, 교육 |
| 2–4 | 프로젝트 |
| 5 | 사이드 프로젝트 |
| 6 | 대외활동 |

문서는 A4 6페이지이며 하단 우측에 `현재 페이지 / 전체 페이지`가 표시된다.

PDF 메타데이터와 실제 페이지 렌더링으로 확인한 값:

- 제작 도구: Figma
- 페이지 크기: `595 × 842pt`인 A4
- 인쇄되는 외곽 테두리: 없음. 앱 미리보기의 그림자는 용지 구분을 위한 UI일 뿐 PDF에는 출력하지 않는다.
- 좌우 외곽 여백: `48pt = 64px = 16.93mm`
- 상단 외곽 여백: `64pt = 85.33px = 22.58mm`
- 본문 높이: `730pt = 973.33px = 257.53mm`
- 2열 세로 구분선의 절대 X 좌표: 약 `154.5–155pt`
- 왼쪽 콘텐츠 시작점에서 2열 세로 구분선까지: 약 `106.5–107pt = 142–142.67px`
- 2열 본문 텍스트 시작점의 절대 X 좌표: `178pt`

CSS의 `px`은 96dpi 기준이고 PDF 좌표의 `pt`는 72dpi 기준이므로 `1pt = 1.3333px`로 환산한다.

## 페이지 하단 규격

- 하단 구분선 중심: 페이지 위에서 약 `802.75pt`, 아래에서 약 `39.25pt = 52.33px`
- 하단 구분선 시작점: `x = 48pt`
- 하단 구분선 끝점: 약 `x = 500.5pt`
- 페이지 번호 시작점: 약 `x = 525.1pt`
- 페이지 번호 기준선: 페이지 아래에서 약 `36pt = 48px`
- 페이지 번호 오른쪽 끝: 약 `x = 547pt`, 페이지 오른쪽 여백과 일치

## 전역 시각 규칙

- 흰색 페이지와 넓고 일정한 외곽 여백
- 검정·진회색 본문과 선명한 파란색 강조색
- 얇은 연회색 구분선
- 산세리프 한글 서체
- 제목, 항목 제목, 본문, 보조 정보가 명확히 구분되는 굵기와 크기
- 링크의 아이콘과 밑줄 표현
- 페이지 하단 우측의 고정 페이지 번호
- 페이지 번호 왼쪽까지 이어지는 짙은 회색 하단 구분선

정확한 색상, 크기와 간격은 구현 과정에서 PDF 렌더링 결과를 비교하며 토큰으로 확정한다.

## 확정된 타이포그래피와 색상

- 기본 서체: `Pretendard`, 시스템 한글 산세리프 순서의 fallback
- 섹션 제목: `18pt`
- 프로필 직무명: `12pt`, `#2b77ec`
- 프로필 이름: `16pt`
- 소개 본문: `10pt / 16pt`
- 경력·교육·프로젝트·대외활동 제목: `10pt`
- 날짜·소속·링크·요약: `8pt`
- 상세 항목 제목: `8pt`
- 상세 항목 본문: `7pt / 10pt`
- 프로젝트와 사이드 프로젝트 제목: `#0064ff`
- 기본 본문: `#222`

한글 줄바꿈은 단어 단위 강제 유지가 아니라 원본과 같은 일반 줄바꿈 규칙을 사용한다. 따라서 이 스타일에서는 `word-break: normal`을 적용한다.

## 1페이지 구조

- 좌측 프로필 사진, 직무명과 이름
- 우측 연락처와 외부 링크
- 소개 제목과 여러 개의 본문 문단
- 문단 안의 선택적 굵은 강조
- 가로 구분선
- 경력의 날짜·기간과 본문을 나눈 2열 구성
- 교육 항목

경력은 2열 구조를 사용하지만 교육은 날짜와 제목을 한 열에 쌓는다. 섹션이 같은 페이지 중간에서 시작하면 위쪽 가로 구분선을 표시하고, 새 페이지 첫 섹션이면 구분선을 생략한다.

## 프로젝트 페이지 구조

프로젝트 항목은 왼쪽 메타데이터 열과 오른쪽 본문 열로 나뉜다.

```text
날짜·소속·링크 │ 프로젝트 제목
                │ 프로젝트 요약
                │ ■ 성과 제목
                │   │ 문제 설명
                │   │ → 해결 과정
                │   │ → 결과
                │ 기술 스택
```

본문에는 다음 계층이 반복된다.

1. 파란색 프로젝트 제목
2. 프로젝트 요약 문단
3. 사각 bullet이 있는 성과 제목
4. 세로선과 들여쓰기가 적용된 상세 설명
5. 화살표로 시작하는 해결 과정과 결과
6. 아이콘이 있는 기술 스택

## 문단 내부 표현

하나의 문단 안에서 다음 표현이 혼합된다.

- 일반 텍스트
- 굵은 텍스트
- 밑줄 텍스트
- 굵게와 밑줄의 조합
- 링크

따라서 문단을 단일 문자열과 단일 스타일만으로 저장해서는 참조 PDF를 재현할 수 없다.

## 페이지 연결 규칙

일부 프로젝트는 다음 페이지까지 이어진다.

- 이어지는 페이지에서 프로젝트 제목을 불필요하게 반복하지 않는다.
- 이어지는 본문은 이전 페이지와 동일한 본문 열에 정렬한다.
- 왼쪽 메타데이터 영역은 필요에 따라 비워 둔다.
- 한 프로젝트의 기술 스택까지 완료한 뒤 다음 프로젝트를 시작한다.
- 섹션 제목은 해당 섹션의 첫 페이지에만 표시한다.

참조 문서에서는 대외활동이 6페이지에서 새로 시작한다. `reference-v1` 레이아웃은 이 구성을 보존하기 위해 대외활동 섹션에 명시적인 새 페이지 시작 규칙을 적용한다.

## 섹션별 비교 결과

PDF 텍스트 기준선과 앱에서 다시 출력한 PDF의 좌표를 대조한 결과다.

| 구간 | 결과 |
|---|---|
| 페이지 외곽과 하단 페이지 번호 | A4 6페이지, 좌우 `48pt`, 상단 `64pt`, 기준선 오차 약 `0.3pt` |
| 프로필·소개·경력·교육 | 주요 기준선과 열 정렬 일치 |
| 프로젝트 | 원본과 동일하게 2–4페이지에 배치되고 이어지는 항목의 제목을 반복하지 않음 |
| 사이드 프로젝트 | 5페이지 배치, 제목·기간·요약·링크·상세 항목의 주요 기준선 오차 약 `0–1pt` |
| 대외활동 | 6페이지 배치, 제목·본문·불릿·기술 스택의 주요 기준선 오차 약 `0–1pt` |
| 프리텍스트 | 참조 PDF와 현재 JSON에 내용이 없어 직접 비교 대상 없음. 공통 섹션 제목과 콘텐츠 블록 스타일을 사용함 |

외부 JSON의 문장과 링크는 수정하지 않았다. 출력 검증에서는 JSON의 277개 텍스트 값과 21개 링크가 참조 PDF에 존재하며, 참조 PDF의 텍스트 항목이 앱 출력 PDF에서 누락되지 않았음을 확인했다.

## 구현 시 확인할 자산

- 실제 사용 서체와 굵기
- 프로필 이미지
- 링크와 기술 스택 아이콘
- 정확한 파란색과 회색 값
- PDF 내부 링크의 클릭 가능 여부

자산과 수치는 추측으로 확정하지 않고 실제 출력 비교를 통해 결정한다.
