# 참조 PDF 분석

## 문서 구성

| 페이지 | 주요 구성 |
|---|---|
| 1 | 프로필, 소개, 경력, 교육 |
| 2–4 | 프로젝트 |
| 5 | 사이드 프로젝트 |
| 6 | 대외활동 |

문서는 A4 6페이지이며 하단 우측에 `현재 페이지 / 전체 페이지`가 표시된다.

PDF 메타데이터와 실제 페이지 렌더링으로 확인한 값:

- 제작 도구: Figma
- 페이지 크기: `595 × 842pt`인 A4
- 좌우 외곽 여백: 약 `17mm`
- 상단 외곽 여백: 약 `23mm`
- 왼쪽 콘텐츠 시작점에서 2열 세로 구분선까지 약 `37–38mm`

## 전역 시각 규칙

- 흰색 페이지와 넓고 일정한 외곽 여백
- 검정·진회색 본문과 선명한 파란색 강조색
- 얇은 연회색 구분선
- 산세리프 한글 서체
- 제목, 항목 제목, 본문, 보조 정보가 명확히 구분되는 굵기와 크기
- 링크의 아이콘과 밑줄 표현
- 페이지 하단 우측의 고정 페이지 번호
- 페이지 번호 왼쪽까지 이어지는 짙은 회색 하단 구분선

정확한 색상, 크기와 간격은 구현 과정에서 PDF 렌더링 결과를 비교하며 토큰으로 확정한다.

## 1페이지 구조

- 좌측 프로필 사진, 직무명과 이름
- 우측 연락처와 외부 링크
- 소개 제목과 여러 개의 본문 문단
- 문단 안의 선택적 굵은 강조
- 가로 구분선
- 경력의 날짜·기간과 본문을 나눈 2열 구성
- 교육 항목

경력은 2열 구조를 사용하지만 교육은 날짜와 제목을 한 열에 쌓는다. 섹션이 같은 페이지 중간에서 시작하면 위쪽 가로 구분선을 표시하고, 새 페이지 첫 섹션이면 구분선을 생략한다.

## 프로젝트 페이지 구조

프로젝트 항목은 왼쪽 메타데이터 열과 오른쪽 본문 열로 나뉜다.

```text
날짜·소속·링크 │ 프로젝트 제목
                │ 프로젝트 요약
                │ ■ 성과 제목
                │   │ 문제 설명
                │   │ → 해결 과정
                │   │ → 결과
                │ 기술 스택
```

본문에는 다음 계층이 반복된다.

1. 파란색 프로젝트 제목
2. 프로젝트 요약 문단
3. 사각 bullet이 있는 성과 제목
4. 세로선과 들여쓰기가 적용된 상세 설명
5. 화살표로 시작하는 해결 과정과 결과
6. 아이콘이 있는 기술 스택

## 문단 내부 표현

하나의 문단 안에서 다음 표현이 혼합된다.

- 일반 텍스트
- 굵은 텍스트
- 밑줄 텍스트
- 굵게와 밑줄의 조합
- 링크

따라서 문단을 단일 문자열과 단일 스타일만으로 저장해서는 참조 PDF를 재현할 수 없다.

## 페이지 연결 규칙

일부 프로젝트는 다음 페이지까지 이어진다.

- 이어지는 페이지에서 프로젝트 제목을 불필요하게 반복하지 않는다.
- 이어지는 본문은 이전 페이지와 동일한 본문 열에 정렬한다.
- 왼쪽 메타데이터 영역은 필요에 따라 비워 둔다.
- 한 프로젝트의 기술 스택까지 완료한 뒤 다음 프로젝트를 시작한다.
- 섹션 제목은 해당 섹션의 첫 페이지에만 표시한다.

## 구현 시 확인할 자산

- 실제 사용 서체와 굵기
- 프로필 이미지
- 링크와 기술 스택 아이콘
- 정확한 파란색과 회색 값
- PDF 내부 링크의 클릭 가능 여부

자산과 수치는 추측으로 확정하지 않고 실제 출력 비교를 통해 결정한다.
