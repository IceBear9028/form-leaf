# UI/UX 설계

## 목표

사용자가 레이아웃 도구를 배우지 않고 이력서 내용을 입력하면, 오른쪽에서 참조 PDF 수준의 결과를 즉시 확인하고 PDF로 내보낼 수 있게 한다.

이번 작업의 앱 UI는 콘텐츠 편집 도구다. 색상, 글꼴, 간격과 좌표를 직접 조정하는 디자인 도구로 만들지 않는다.

## 기본 화면

```text
┌─────────────────────────────────────────────────────────────────┐
│ Resume Studio       저장됨                75%  맞춤  PDF 내보내기 │
├───────────────────────────┬─────────────────────────────────────┤
│ 편집 패널                 │ 미리보기                            │
│                           │                                     │
│ 프로필                    │          ┌───────────────┐          │
│ 소개글                    │          │     1 / 6     │          │
│ 경력                      │          │               │          │
│ 교육                      │          └───────────────┘          │
│ 프로젝트                  │                                     │
│ 사이드 프로젝트          │          ┌───────────────┐          │
│ 대외활동                  │          │     2 / 6     │          │
│ 프리텍스트                │          │               │          │
│                           │          └───────────────┘          │
└───────────────────────────┴─────────────────────────────────────┘
```

- 상단에는 저장 상태, 미리보기 zoom과 PDF 내보내기만 둔다.
- 왼쪽은 편집 패널, 오른쪽은 연속된 A4 페이지 미리보기다.
- 두 영역은 독립적으로 스크롤한다.
- 편집 패널 너비는 조절할 수 있지만 PDF 레이아웃에는 영향을 주지 않는다.
- 앱 실행 시 홈 화면을 거치지 않고 편집 화면을 바로 연다.

## 정보 구조

편집 패널은 다음 섹션을 순서대로 보여준다.

1. 프로필
2. 소개글
3. 경력
4. 교육
5. 프로젝트
6. 사이드 프로젝트
7. 대외활동
8. 프리텍스트

섹션은 접고 펼칠 수 있다. 접힌 상태에서도 항목 개수와 저장 상태를 확인할 수 있다.

## 프로필 입력

- 프로필 사진 선택 및 교체
- 이름
- 직무명
- 전화번호
- 이메일
- 웹사이트 링크 목록

사진은 미리보기에서 참조 PDF와 동일한 원형 crop으로 표시한다. 이번 작업에서는 확대·위치 조정 같은 이미지 편집 기능을 제공하지 않는다.

## 소개글 입력

- 여러 문단 추가·삭제·정렬
- 일반 텍스트 입력
- 선택 영역의 굵게, 밑줄과 링크 지정
- 문단별 스타일 선택 기능은 제공하지 않음

소개글의 문단 스타일은 위치와 역할에 따라 `reference-resume-v1`에서 자동 적용한다.

## 타임라인 입력

경력, 교육과 대외활동은 같은 기본 편집 패턴을 사용한다.

- 기간
- 기관 또는 회사명
- 제목 또는 역할
- 링크 목록
- 콘텐츠 블록

화면에서는 각각 별도 섹션으로 보이지만 공통 TimelineItem 편집 컴포넌트를 사용한다.

## 프로젝트 입력

프로젝트와 사이드 프로젝트는 카드 목록으로 편집한다.

카드 요약:

```text
[기간] 프로젝트명                         [접기]
소속 · 콘텐츠 블록 4개
```

카드를 펼치면 다음을 입력한다.

- 기간
- 소속
- 프로젝트명
- 프로젝트 소개
- 링크
- 상세 콘텐츠 블록
- 기술 스택

항목은 추가, 삭제와 위·아래 이동을 지원한다. 첫 구현에서는 drag and drop을 필수로 하지 않는다.

## 콘텐츠 블록 편집

프로젝트와 프리텍스트는 같은 블록 편집기를 사용한다.

추가할 수 있는 블록:

- 문단
- bullet 목록
- 성과 상세 블록
- 링크 목록
- 기술 스택

블록마다 다음 동작을 제공한다.

- 추가
- 삭제
- 위로 이동
- 아래로 이동
- 접기·펼치기

성과 상세 블록은 참조 PDF의 구조에 맞춰 다음 필드를 제공한다.

```text
성과 제목
문제 또는 배경
해결 과정
결과
```

## 텍스트 편집

텍스트 선택 시 최소한의 인라인 도구만 표시한다.

```text
[굵게] [밑줄] [링크]
```

- 글꼴, 크기, 색상과 행간 버튼은 제공하지 않는다.
- Enter는 새 문단 또는 현재 블록 규칙에 맞는 새 행을 만든다.
- 한글 IME 조합 중 자동 저장이나 미리보기 갱신이 입력을 끊지 않아야 한다.

## 미리보기

- 모든 변경은 입력 직후 A4 미리보기에 반영한다.
- 페이지는 세로로 연속 배치한다.
- `페이지 맞춤`, `너비 맞춤`, zoom 비율을 제공한다.
- 미리보기의 페이지 번호는 최종 PDF와 같다.
- 미리보기에서 스타일을 직접 수정하지 않는다.

초기 구현에서는 편집 항목과 미리보기의 양방향 선택·강조는 필수 기능으로 두지 않는다.

## 자동 저장

상단에 다음 상태만 표시한다.

- 저장 중
- 저장됨 · 시각
- 저장 실패

입력 중에는 메모리 상태와 미리보기를 즉시 갱신하고 짧은 debounce 이후 로컬 파일에 저장한다. 저장 실패 시 현재 입력을 유지하고 다시 시도할 수 있게 한다.

## PDF 내보내기

```text
PDF 내보내기 선택
→ 현재 입력 저장 완료 확인
→ PDF 준비
→ 저장 위치 선택
→ 저장 완료
```

- 별도의 스타일 선택 단계는 없다.
- 시스템 프린터 인쇄는 제공하지 않는다.
- 실패하면 현재 편집 상태를 유지하고 재시도를 제공한다.
- 성공하면 저장 위치와 Finder에서 보기 동작을 제공한다.

## 빈 상태와 오류 상태

- 최초 실행: 샘플 문장 없이 빈 입력 필드를 표시한다.
- 프로필 사진 없음: 참조 레이아웃 크기를 유지하는 중립 placeholder를 표시한다.
- 저장 실패: 입력을 막지 않고 상단에 오류와 재시도를 표시한다.
- PDF 생성 실패: 원인을 짧게 표시하고 편집 화면에 그대로 머문다.
- 필수 자산 없음: PDF 생성 전 누락 항목을 구체적으로 표시한다.

## 키보드와 접근성

- 모든 입력은 명시적인 label을 가진다.
- 아이콘 버튼에는 텍스트 대체 이름을 제공한다.
- 블록 이동은 키보드 버튼으로 가능해야 한다.
- `⌘Z`, `⇧⌘Z`는 텍스트 입력의 기본 undo/redo를 지원한다.
- 저장 상태와 오류는 색상만으로 전달하지 않는다.

## 이번 작업에서 제공하지 않는 UI

- 색상 선택
- 글꼴과 글자 크기 선택
- 행간과 문단 간격 입력
- 페이지 여백 조정
- 자유 좌표 배치
- 스타일 템플릿 선택
- 여러 이력서 문서 관리
- JSON 가져오기·내보내기
