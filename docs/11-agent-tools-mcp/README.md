# 11. 에이전트 도구와 로컬 MCP

## 작업 소개

**외부 에이전트가 허용된 문서를 탐색·수정·출력하고 저장 결과를 확인하게 한다.**

- 대상 사용자: Formleaf 문서 작성자와 연결된 외부 에이전트.
- 해결할 문제: 화면 조작과 복사·붙여넣기 없이도 입력 중인 문서와 권한 범위를 보호해야 한다.

## 핵심 변화

**앱 내부 편집 기능을 문서 권한과 저장 보호를 갖춘 MCP 도구로 연결한다.**

- 변경 전: 사용자가 앱에서 직접 문서를 찾아 수정하고 출력한다.
- 변경 후: 에이전트가 명시적 target과 저장 revision으로 변경하고 PNG/PDF 및 영속 작업 결과를 확인한다.
