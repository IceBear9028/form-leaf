# 프리뷰 Markdown 편집 사용성 계약

## 목적

프리뷰 편집은 작은 입력 필드의 모음이 아니라 하나의 연속적인 텍스트 편집기처럼 느껴져야 한다. Markdown 원문을 안전하게 유지하는 것은 내부 구현의 책임이며, 사용자가 marker나 페이지 재측정을 의식하게 해서는 안 된다.

## 핵심 원칙

1. **포커스는 사용자의 명시적인 이동 전까지 유지한다.** 일반 입력, 삭제, Enter, 서식 적용과 페이지 재배치가 편집 포커스를 해제하면 안 된다.
2. **편집 단위는 화면의 Markdown 블록이다.** 문장 안의 굵게·링크·밑줄 조각은 별도 입력칸으로 취급하지 않는다.
3. **보이는 글자를 기준으로 편집한다.** Backspace와 Delete는 Markdown marker가 아니라 화면의 이전·다음 글자를 삭제한다.
4. **한글 조합 중에는 다시 렌더링하지 않는다.** 조합 중간 문자열은 로컬 DOM에 두고 `compositionend`에서 한 번만 원문에 반영한다.
5. **페이지네이션은 입력을 방해하지 않는다.** 재측정 후에도 같은 source range에 커서와 선택을 복원하며 불필요한 스크롤을 만들지 않는다.

## 키보드 동작

| 입력 | 기대 동작 |
|---|---|
| 일반 문자·한글 | 현재 커서에 입력하고 포커스와 커서를 유지한다. |
| Space | 문장 끝에서도 공백을 원문과 화면의 편집 위치에 즉시 반영한다. 서식 끝에서는 닫는 marker 바깥에 공백을 넣는다. |
| 방향키 | 같은 블록 안의 서식 경계를 끊김 없이 이동한다. |
| Shift+방향키 | 같은 편집 그룹 안에서 선택 범위를 확장한다. |
| Backspace | 선택 영역 또는 화면의 이전 grapheme 한 개를 삭제한다. 새 줄 맨 앞에서는 직전 줄바꿈을 삭제해 이전 줄과 합친다. |
| Cmd/Ctrl+Backspace | 블록 전체가 아니라 현재 커서부터 현재 시각적 줄 시작까지만 삭제한다. |
| Delete | 선택 영역 또는 화면의 다음 grapheme 한 개를 삭제한다. |
| Enter | 현재 위치에서 Markdown 블록을 나누고, 새 블록의 맨 왼쪽에 커서를 놓는다. |
| Enter 연속 입력 | 누를 때마다 편집 가능한 새 빈 블록을 하나씩 추가한다. |
| Shift+Enter | 현재 블록을 나누지 않고 블록 안에 강제 줄바꿈을 추가한다. |
| 붙여넣기 | HTML 서식을 제거하고 plain text만 삽입한다. |
| Cmd/Ctrl+B | 선택 영역의 굵게를 적용·해제한다. |
| Cmd/Ctrl+I | 선택 영역의 기울임을 적용·해제한다. |
| Cmd/Ctrl+U | 선택 영역의 밑줄을 적용·해제한다. |
| Cmd/Ctrl+Z | 짧은 시간 동안 이어진 입력을 한 단위로 실행 취소한다. |
| Cmd/Ctrl+Shift+Z·Ctrl+Y | 마지막으로 취소한 편집을 다시 실행한다. |
| Escape | 선택 도구를 닫고 현재 선택을 해제한다. |

## 포커스와 선택

- 한 Markdown 블록에는 하나의 `contentEditable` 편집 host만 둔다.
- 인라인 텍스트 조각은 source offset metadata만 가지며 별도 편집 host가 아니다.
- 일반 입력 후 커서는 변경된 원문의 `selectionAfter`로 복원한다.
- 문장 끝의 공백·탭은 parser가 화면 노드에서 제외하더라도 별도의 source-mapped 구간으로 렌더링한다. 연속 Space 뒤에도 커서는 마지막 공백 다음에 있어야 한다.
- Backspace 후 source offset이 Markdown trailing space나 marker처럼 화면에 없는 구간에 놓이면 가장 가까운 이전 화면 경계에 복원한다. 남은 글자가 있는데 블록 맨 앞으로 이동하면 안 된다.
- Enter 후에는 시작·끝 노드가 다른 0글자 선택을 만들지 않는다. 새 블록 시작 source offset에 하나의 접힌 caret을 만들고 즉시 다음 글자를 입력할 수 있어야 한다.
- 커서가 텍스트 노드가 아니라 문단·강조·링크의 자식 경계에 있어도 inline marker의 바깥/안쪽 source offset을 구분한다.
- 드래그 선택 후 toolbar를 눌러도 원래 선택을 유지한다.
- 서로 다른 문단·제목·목록 항목을 가로지른 선택에는 인라인 서식 도구를 표시하지 않는다.
- 페이지가 늘거나 줄어도 편집 중인 블록으로 강제 스크롤하지 않는다. 사용자가 보던 위치를 우선한다.

## 입력 처리 규칙

- 일반 키 입력은 `beforeinput`에서 브라우저 DOM 변경을 막고 source range 트랜잭션으로 처리한다.
- 삭제 범위는 DOM text offset을 단순히 1 감소시키지 않고 화면 grapheme과 source boundary를 사용한다.
- Shift+Enter는 제목·문단·목록에서 동일하게 동작하도록 Markdown 인라인 강제 줄바꿈 `<br>`로 저장한다. 렌더러는 이를 실행 가능한 HTML이 아닌 source-mapped 줄바꿈 요소로 제한해 표시한다.
- 블록 끝의 `<br>` 뒤에는 새 줄 시작점을 나타내는 전용 caret anchor를 즉시 렌더링한다. 다음 글자가 입력되기 전에도 커서는 새 줄 맨 왼쪽에 보여야 한다.
- Enter는 경계의 불필요한 공백을 정리하고 원문에 빈 줄을 삽입해 앞·뒤 내용을 서로 다른 Markdown 블록으로 분리한다.
- Markdown AST는 내용 없는 문단을 만들지 않으므로 Enter로 추가된 빈 블록은 독립적인 `.markdown-empty-block-host` `contentEditable` 형제로 합성한다. 기존 host 내부에 중첩하지 않으며, `document.activeElement`와 커서는 즉시 새 host로 이동해야 한다.
- 빈 블록 시작에서 Backspace를 누르면 해당 블록을 만든 `\n\n` 전체를 제거하고 직전 블록 끝으로 돌아간다.
- 문단 사이의 빈 줄에 공백이나 탭이 섞여 있어도 각 편집 가능 줄의 source offset을 계산한다. 해당 줄 맨 앞의 Backspace는 직전 `\n` 하나를 삭제한다.
- caret anchor의 제로폭 placeholder는 DOM에서만 사용하며 Markdown 원문에 저장하지 않는다.
- 제목·굵게·밑줄·취소선의 마지막 글자를 지워도 marker는 화면 텍스트의 삭제 대상으로 취급하지 않는다. 빈 서식 anchor를 유지해 같은 효과로 바로 다시 입력할 수 있어야 한다.
- 굵게·기울임·밑줄·취소선·링크의 마지막 글자 뒤에서 Space를 입력하면 닫는 marker 뒤에 삽입한다. `**텍스트 **`처럼 공백 때문에 서식 문법이 깨진 원문을 만들지 않는다.
- 블록 첫 화면 글자 앞에서 Backspace를 눌렀을 때 같은 편집 그룹에 이전 화면 글자가 없으면 아무 원문도 삭제하지 않는다.
- 입력한 일반 문자는 의도치 않은 Markdown 구조로 바뀌지 않도록 필요한 문자를 escape한다.
- IME 조합만 브라우저의 임시 DOM 변경을 허용하며 조합 종료 전에는 문서 상태·자동 저장·페이지 측정을 갱신하지 않는다.
- 강제 줄바꿈 직후 caret에서 IME 조합이 끝나면 브라우저가 삽입한 임시 글자를 caret DOM에서 먼저 제거한 뒤 원문을 갱신한다. 같은 글자가 임시 DOM과 React 텍스트에 중복 표시되면 안 된다.
- 코드 블록, 표, 이미지, 원문 HTML과 각주는 읽기 전용을 유지한다.

## 오류와 예외

- source range를 안전하게 계산할 수 없으면 브라우저 DOM을 임의로 저장하지 않고 입력을 취소한다.
- 지원하지 않는 구조 변경은 원문을 손상시키지 않으며 왼쪽 Markdown 편집기에서 계속 편집할 수 있다.
- 링크는 `http:`, `https:`, `mailto:`만 저장한다.

## 완료 기준

- 문장 중간에서 20자 이상 연속 입력해도 포커스나 커서가 이동하지 않는다.
- 문장 마지막에서 Space를 한 번 이상 입력한 뒤 바로 다음 글자를 쓰거나 Backspace로 공백을 지울 수 있다.
- 굵게·링크·밑줄 경계를 방향키와 Backspace로 자연스럽게 통과한다.
- Enter를 누르면 커서가 새 블록 맨 왼쪽으로 이동하며, 별도 클릭 없이 즉시 다음 글자를 입력할 수 있다.
- 새 블록 맨 왼쪽에서 Backspace를 누르면 블록 경계가 제거되어 이전 블록과 합쳐진다.
- 연속 Backspace 중 매 입력 뒤 커서는 삭제된 grapheme의 바로 앞에 머물며, 숨은 Markdown 경계 때문에 블록 시작이나 다른 문장으로 이동하지 않는다.
- Cmd/Ctrl+Backspace는 Shift+Enter 줄과 자동으로 접힌 시각적 줄 모두에서 현재 줄 범위만 삭제하며 나머지 블록 텍스트를 유지한다.
- 서식 구간의 마지막 글자를 삭제한 뒤 다시 입력해도 제목·굵게·밑줄 효과가 유지된다.
- Enter를 연속 입력해 새 블록을 계속 만들 수 있고, Shift+Enter로는 현재 블록 안에서만 줄을 바꿀 수 있다.
- 한글 자모가 분리되거나 조합 중간 문자열이 자동 저장되지 않는다.
- 입력으로 블록이 다음 페이지로 이동해도 편집을 계속할 수 있다.
- 붙여넣은 rich text가 HTML로 저장되지 않는다.
- 서식 적용 뒤에도 선택 영역이 유지된다.
